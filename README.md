# AIR Personal OS • V1 Expo

Aplicativo demonstrativo em **Expo + React Native Web**, com UI clara, assets SVG, navegação desktop/mobile, tarefas com lista/Kanban/grade, lista de compras persistente, finanças e saúde ilustrativas, agenda, metas e insights.

## Executar

```bash
npm install
npm run check
npm run web
# npm start (Expo Go)
```

**ZIP incluído:** `AIR_V1.zip` tem o código da V1 e os assets vetoriais. Apenas a biblioteca original de PNG/JPG fotorrealistas do `AIR_EXPO_MVP.zip` criado na conversa permanece pendente de importação, já que o conector não recebe uploads binários locais. Não se deve afirmar que esses PNG/JPG foram enviados.

## Privacidade e integrações

Os dados exibidos são **demonstrações**. Open Finance será exclusivamente para leitura de gastos autorizados. Saúde, calendários, NFC-e e IA real serão tratados numa fase posterior.

Leia `AGENTS.md` e `CODEX_HANDOFF.md` antes de modificar UI.
