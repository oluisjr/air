# AIR • Codex

Produto comercial premium, não um tutorial. UI tema claro, poucos cards, respiro, tipografia fina com títulos amplos, cores branco, azul-petróleo e aqua. Liquid Glass **seletivo**, sem exageros. Navegação responsiva desktop/mobile.

Stack Expo + React Native Web + TypeScript. Não confundir dados de demonstração com integrações reais. Open Finance: leitura autorizada somente de despesas, jamais pagamentos/transações. NFC-e depende de fontes fiscais e regras por UF. Mi Fitness: Health Connect / Apple Saúde, conforme permissões. Testar fluxos antes de declarar pronto.

Os SVGs estão versionados. Os PNG/JPG fotorrealistas do pacote anterior ainda devem ser importados de `AIR_EXPO_MVP.zip` em `assets/images/`, sem substituir silenciosamente por placeholders.
