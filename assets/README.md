# Biblioteca vetorial AIR

Os SVGs neste diretório são assets reais do app: `brand/air-wordmark.svg`, `backgrounds/lake-hero.svg`, `backgrounds/flow.svg`, `effects/glass-panel.svg`, `effects/glass-ring.svg` e `illustrations/nfce-scanner.svg`.

`src/assets.ts` fornece o mesmo SVG inline para `react-native-svg` no Expo. Os fundos fotorrealistas originais ainda dependem de importação do ZIP do projeto prévio.
